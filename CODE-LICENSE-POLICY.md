# Code License Policy

This repository uses a split-license model so that book text and
runnable code have clearly defined licensing terms.

- **Book text and instructional prose:** Creative Commons
  Attribution-NonCommercial-ShareAlike 4.0 International
  (CC BY-NC-SA 4.0). See [`LICENSE`](LICENSE).
- **Free code samples and project code:** MIT License.
  See [`LICENSE-CODE.md`](LICENSE-CODE.md).
- **Paid content and code:** Excluded from the licences above.
  Their licensing and distribution terms will be determined
  separately when the paid edition is prepared for publication.

## What counts as code

The MIT license applies to source code files and executable
examples in:

- `/free/content/examples/`
- `/free/project-solutions/`

The MIT license does **not** automatically apply to:

- Paid content or paid project solutions.
- Chapter text, explanatory prose, or other non-code documentation.

## Paid content

Paid content and associated code are excluded from the MIT
license and the CC BY-NC-SA 4.0 license specified for the
free edition.

Their licensing, publication, and distribution terms will
be determined separately before the paid edition is released.

## Contributor attribution policy for non-original code

If you add code that you did not author:

1. Confirm the upstream license permits inclusion and redistribution.
2. Keep the original copyright and license headers when required.
3. Add a short source attribution comment at the top of the
   file (or in the nearest README when file headers are not practical).
4. Include any required third-party notices in this repository.
